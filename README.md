# Todo List Web App

A simple browser-based todo list made with HTML, CSS, and vanilla JavaScript.

## Features

- Add and delete tasks
- Cycle task status through Pending, Correct, and Wrong
- Save tasks in browser `localStorage`
- Responsive layout for small screens

## Run locally

Open `index.html` in a modern web browser. No build tools or dependencies are
required.

## Add the project to Git

Run these commands from this folder:

```sh
git init
git add index.html css/style.css js/app.js README.md .gitignore
git commit -m "Add todo list web app"
```
